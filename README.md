# Aloha Nails AI Photoshoot Pro

High-fashion creative studio that generates flawless Aloha Nails product photography with palette-locked manicures, couture styling, and compliance-ready overlays.

## Features

- Editorial hero section showcasing the AI output with on-brand compliance badge.
- Interactive prompt builder that keeps manicure, wardrobe, and environment in sync.
- Dynamic copy explaining the production workflow and trusted differentiators.
- Gallery module highlighting social, OOH, and macro-ready image variations—all stamped with `TPO FREE • HEMA FREE`.

## Local Development

```bash
npm install
npm run dev
```

Visit `http://localhost:3000` to explore the experience.

## Production Build

```bash
npm run lint
npm run build
```

The site is live on **https://agentic-a869bf6a.vercel.app**.
